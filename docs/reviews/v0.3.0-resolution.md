# Resolution of the v0.2.0 review

The [original audit](thermo-nuclear-v0.2.0.md) recorded three P1 and three P2 findings, with no P0 findings. Version 0.3.0 addresses all six and implements the missing Markdown capabilities identified by that audit.

| Finding | Resolution | Regression proof |
| --- | --- | --- |
| F1 — P1: diff replay and replaced DOM | Python emits semantic HTML; the shared browser text renderer reconciles leaves and retains stable elements. Deltas append their own diff chunks. | Public npm snapshot sequences; retained paragraph, nested and keyed nodes; unchanged prefix animation and selection |
| F2 — P1: sanitizer rejects renderer output | Both runtimes use `schema.json` for HTML properties and option defaults. Invalid URLs lose their URL attribute without aborting the update; table alignment survives sanitization. | Python malformed links; browser malformed/unsafe URL corpus; computed left/right table alignment |
| F3 — P1: newline layout | Whitespace stays in native text nodes; animated word spans do not enclose standalone newlines. Code keeps native `pre` layout. | Exact multiline source plus browser geometry for plain text and highlighted code |
| F4 — P2: mounting and disposal | Initial animation is explicit, destruction releases mount ownership, and `unmount` cancels pending work and resolves waiters. | Automatic populated-page mounting; disabled initial animation; reduced motion; destroy/remount/unmount cycles; cancelled work |
| F5 — P2: insufficient parity tests | The oracle renders the public npm `AnimatedMarkdown` export. Tests preserve whitespace and distinguish parity comparisons from port regressions and framework integration. | Public static/streamed Markdown; 13 computed animation effects; themes, clipboard feedback, delayed/failed images and custom tags |
| F6 — P2: append rescans/copies history | Python appends to the existing chunk list; JavaScript tokenizes only the new delta plus the boundary token. | Chunk-list identity and forbidden snapshot-path test; measured maximum tokenizer input of six characters during appends to a 5,000-character browser stream |

The plain-text and Markdown engines now share token scheduling rather than maintaining separate token trees in Python and JavaScript. The browser source is split by responsibility into text scheduling, DOM reconciliation, component behaviors, settings and public lifecycle. The generated dependency-free bundle is reproducible and checked in CI.

## Added capabilities

- Syntax highlighting uses Pygments themes, including foreground/background colors and unknown-language fallback. Code controls copy the exact complete source and display success, failure and reset states.
- Markdown images expose height, width and fit options. Loading gates the configured animation; failed loads reveal alt text, and unchanged images survive updates.
- Python custom-tag callbacks receive typed component data and produce sanitized markup. Recognized incomplete tags stay hidden; Markdown code remains literal. Stable keys retain interactive DOM state.
- Timing accepts keyword, cubic-bezier and steps values. Links open with safe new-tab attributes. Default raw HTML remains escaped; optional trusted HTML still uses the allowlist.

## Deliberate differences from npm

This is a Python adaptation, not a React runtime. Pygments theme names replace JavaScript theme objects; server callbacks replace React custom components. Callbacks are for registered raw tags, not arbitrary React prop overrides. Browser application code can attach interactions to retained keyed elements.

Raw HTML always passes the allowlist. Unicode uses code points rather than reproducing UTF-16 splitting. Snapshot corrections and resets are supported. The typewriter effect clips text rather than animating its layout width; the other 13 effects match the reference's computed keyframes. Wrapper elements and syntax-highlighter colors are not pixel-identical.

Full Markdown snapshots still require parsing the document. Producing a full text snapshot still costs proportional to its length. The append fix removes redundant chunk-list copies and history tokenization; it does not claim constant-time full snapshots.

## Verification

The release gate is `pytest -q`, `npm test`, and `python -m build --no-isolation`. Browser tests use the pinned `flowtoken@1.0.40` package. Framework tests run real FastHTML, Flask and Django servers and stream SSE into a browser. CI additionally installs the built wheel outside the checkout and verifies that rebuilding the browser bundle leaves it unchanged.

Local verification passed: 45 Python tests, 61 public-oracle comparisons, 65 runtime regressions, seven image checks, one automatic-mount check, three live framework demos, and an installed-wheel smoke test. No P0, P1 or P2 findings remain open from the original audit.
