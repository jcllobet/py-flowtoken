# Shared streaming contract

The renderers and browser animator are identical across FastHTML, Flask, and Django. Framework adapters only register assets, integrate templates, and return framework-native streaming responses.

Create one `TextStream` per conversation/request:

```python
from py_flowtoken import TextStream

stream = TextStream()
first = stream.append('Hello ')
second = stream.append('world')
correction = stream.update('Hello, everyone')
```

`append()` accepts a new chunk. `update()` accepts the full latest text. An `Update` contains `text`, `delta`, `reset`, and `revision`. Each adapter's `event_stream()` serializes updates as SSE messages named `flowtoken`.

A synchronous generator usable with all three adapters:

```python
def events():
    state = TextStream()
    for chunk in your_text_producer():
        yield state.append(chunk)
    yield 'event: done\ndata: {}\n\n'
```

Return `event_stream(events())` from your framework's view. FastHTML and Django additionally accept asynchronous generators. Your application owns the stream endpoint, its authorization, and its producer.

In the browser, import the URL generated by your framework adapter and connect it to the rendered `id='answer'` component:

```javascript
import {mount} from '/flowtoken/flowtoken.js';

const view = mount(document.getElementById('answer'));
const source = new EventSource('/stream');
source.addEventListener('flowtoken', event => {
  view.setText(JSON.parse(event.data).text);
});
source.addEventListener('done', () => source.close());
window.addEventListener('pagehide', () => {
  source.close();
  view.destroy();
}, {once: true});
```

Use `flowtoken_asset_url` in Flask/Django templates when a custom prefix or static-file storage changes the module URL. The complete examples demonstrate this wiring.

The adapter sets `Content-Type: text/event-stream`, `Cache-Control: no-cache`, and `X-Accel-Buffering: no`. If an upstream proxy still buffers streaming responses, configure that proxy to pass SSE through.

No React, Node server, or npm installation is required at runtime. The package includes the browser module and styles. Node and the original FlowToken package are used only for development comparison tests.
